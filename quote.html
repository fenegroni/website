How it works

  1. 1

    Ask for a quote

    You tell me what you would like help with. This step is free.

  2. 2

    Agree where to start

    I reply by email with a few short questions. We agree which problem to start from, how AI can help with it, and which size fits: £50, £100 or £200. The emails and the quote are free.

  3. 3

    Fix it together

    On a video call with screen sharing, we find the right problem and fix it together. You build the solution alongside me, so you learn how to change it as you go. You keep what we build. It is the proof that the problem is fixed.

  4. 4

    It keeps working

    Your solution keeps working for as long as it does its job. It tells you when it may no longer fit, so you never have to keep checking it yourself. You can make small changes yourself, and you can come back when the problem itself has changed.
