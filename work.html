What I build

ADHD scaffolding

Tools I built for my own ADHD and run daily.

Public on GitHub

adhd-assist

A Claude skill that notices when someone is stuck and offers one small thing that might help. The person writes the rules while they feel well. The skill matches against those rules when they do not. It reads their own judgement back to them at the moment it is hardest to reach.

github.com/fenegroni/adhd-assist
Private, in development

Webcam monitor

A local monitor that watches for signs of fatigue and drift through the webcam. It raises an alert that adhd-assist can act on. The footage stays on the machine, and the code stays small enough to audit.

Private

Pillars and pillar audit

The habits a life rests on, such as sleep, medication and meals, live in plain files. A scheduled agent checks the calendar against them. It books missing sessions, flags what it cannot fix and writes a monthly summary of how each habit went.

Agentic AI

Skills, agents and MCP servers.

Private

Ways of Working skill

A skill that reads a team's retrospective transcripts against the team's own pattern language and the organisational patterns in James Coplien's A Scrum Book. It indexes each pattern by the forces it resolves. It can then name the tension a team is feeling and suggest a pattern to try. I tested it against real retrospective transcripts.

Private

The Librarian

A knowledge base that runs as an agentic system. Notes go in as they arrive. Agents file them, cross-reference them and keep them current, so the knowledge base grows without anyone tending it by hand.

Demo

Multi-source data collator

A skill plus deterministic Python checks that merges returns from many organisations into one auditable dataset. The agent extracts and the code validates. Every value keeps its source text. On six published council returns it found two arithmetic errors in the councils' own figures.

Public on GitHub

pattern-authoring

A skill for writing other skills as Alexandrian patterns. Each rule states the forces it resolves and the conditions under which it stops applying. Five adversarial probes then hunt for defects that survive rereading.

github.com/fenegroni/agentic-pattern-language
Public on GitHub
