Example

When slides swallow the story

When I open slide software first, I lose hours to layouts and fonts. By the end I have slides but no clear story.

What I built

An AI skill works out the story of a talk with me before any slide exists. It takes me through the main point, the audience and the shape of the talk in a few short steps. Only then do we make the slides.

Why build it, when apps exist?

  • It is convenient. It runs inside the AI tool I already use, so I start from a conversation instead of a blank slide.
  • It removes friction. It keeps the layout options out of sight until the story is ready.
  • It was quick to get done, because it is one skill and not a new program.
  • It fits my way of working, because it moves fast through the steps I have already done.

I published the same brief run with and without the skill. The code and both results are public on GitHub.
