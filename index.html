Case study

Local authority data collation

I built a Claude Skill paired with deterministic Python validation to collate stray dog returns from three UK local authorities into one canonical, auditable dataset. The pipeline found two genuine arithmetic errors inside the councils' own published figures, and I verified both against the original source PDFs. The design keeps extraction as agent judgement and validation as separate deterministic code, so each check can be trusted independently of the model.
